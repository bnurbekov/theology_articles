# How to Suggest Edits and Start Discussions

The articles on ReformedBaptists.net are kept in a public GitHub repository. That means anyone can point out a mistake, propose a fix, or start a conversation, and every change is visible and tracked.

**Repository:** [github.com/bnurbekov/theology_articles](https://github.com/bnurbekov/theology_articles)

> **Note:** This guide was generated by AI (Claude, by Anthropic). If anything in it is unclear or does not match how the repository actually works, please open an issue or start a discussion to let us know.

You will need a free GitHub account. You can sign up at [github.com/signup](https://github.com/signup) in about two minutes.

---

## Which option should I use?

| I want to... | Use |
|---|---|
| Fix a typo, a broken link, or a translation error myself | **Suggest an edit** (Option 1) |
| Report a problem but not fix it myself | **Open an issue** (Option 2) |
| Ask a question, share an idea, or talk about an article | **Start a discussion** (Option 3) |

---

## Option 1: Suggest an edit directly

You do not need to install anything. You can do everything in your browser.

1. Open the [repository](https://github.com/bnurbekov/theology_articles) and find the file for the article. Articles in different languages (English, Russian, Kazakh) are separate files, so open the one in the language you want to fix.
2. Click the **pencil icon** (✏️) in the top-right corner of the file. If GitHub asks, click **Fork this repository**. This creates your own copy, and it is normal.
3. Make your change in the editor. Keep it small and focused. One fix per suggestion is easiest to review.
4. Click **Commit changes…** (or **Propose changes**).
5. Write a short description of what you changed and why. For example: *"Fix typo in the third paragraph"* or *"Correct the Russian translation of the second heading."*
6. Click **Propose changes**, then **Create pull request**.

That's it. The site owner will review your suggestion. They may accept it, ask a question, or suggest adjustments. You will get a notification on GitHub when something happens.

### Tips for good edits

- **Say where.** Mention the article, the language, and the paragraph or heading.
- **Give a source** if you are correcting a fact, a quotation, or a reference.
- **Keep one topic per pull request.** Smaller suggestions are reviewed faster.
- **Be patient.** This is a volunteer-run project, so replies may take a few days.

## Option 2: Report a problem (open an issue)

Use this when you notice something wrong but do not want to edit the file yourself.

1. Go to the repository's **Issues** tab: [github.com/bnurbekov/theology_articles/issues](https://github.com/bnurbekov/theology_articles/issues)
2. Click **New issue**.
3. Give it a clear title, such as *"Broken link in the Resources article."*
4. In the description, include:
   - The article name and language
   - The exact text or link that has the problem
   - What you think it should say, if you know
5. Click **Submit new issue**.

Before posting, take a quick look at the open issues to see whether someone has already reported the same thing.

---

## Option 3: Start or join a discussion

Use Discussions for anything that is not a specific fix: questions, ideas for new articles, requests for new translations, or general feedback.

1. Go to the **Discussions** tab: [github.com/bnurbekov/theology_articles/discussions](https://github.com/bnurbekov/theology_articles/discussions)
2. Browse the existing topics. You can reply to any of them by typing in the comment box at the bottom.
3. To start a new topic, click **New discussion**.
4. Choose the category that fits best (for example, *Q&A* or *Ideas*).
5. Write a clear title and your message, then click **Start discussion**.

If you do not see a **Discussions** tab, the feature may not be turned on yet. In that case, open an issue instead (Option 2) and say that you would like to start a discussion.

## Writing in your own language

The site is available in **English, Russian, and Kazakh**. You are welcome to write your issues, discussions, and comments in any of these languages.

---

## Guidelines for everyone

- **Stay on topic.** Keep comments about the article or the project.
- **Be specific.** The more precise you are, the easier it is to help.
- **Do not share private information** such as passwords, personal phone numbers, or addresses. Everything on GitHub is public.

Thank you for helping keep these articles accurate and useful for readers in every language.
